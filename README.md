# soul-trail

A skill that preserves and anchors an AI agent's **soul** — its identity and
memory — as a versioned, Bitcoin-anchored trail.

An agent's soul is the durable content of its workspace: `SOUL.md`, `MEMORY.md`,
identity files, `memory/`, and `skills/`. soul-trail turns that into a git
history and anchors it to Bitcoin (via [gitmark](https://blocktrails.org) and
blocktrails key-chaining), making agent identity **portable, versioned, and
cryptographically timestamped** — credible exit for a soul.

It is the soul-layer counterpart of gitmark: gitmark anchors commits;
soul-trail anchors souls.
